How the three approaches compare

A. Network map overview

Best for a first impression and for spotting clusters, such as the large CIR 2024/2977 and 2026/1731 hubs. It gets busy past a few hundred nodes, so it relies on filters and highlighting to stay readable.

B. CIR coverage matrix analysis

The most precise view: every CIR-to-standard link is a cell, gaps are visible as empty rows or columns, and errata line up with the CIRs they affect. It reads as a table rather than a graph, so it suits the team more than the public.

C. Focus navigator recommended for the public

Scales to any size because it only draws one item and its neighbours, and every item gets a link that can be pasted into an issue or the registries. It matches how people arrive: from one standard or one CIR.
